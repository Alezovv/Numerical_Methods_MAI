## Требования лаборанта

1. Все лабораторные работы сдаются в виде программного кода. Использовать можно любой язык программирования[cite: 7].
2. Входные данные не должны вводиться через консоль или быть захардкожены в коде. Можно сделать небольшое приложение с формой для ввода данных или реализовать чтение данных из файла[cite: 7].
3. Программа должна быть универсальной. Размерность матрицы не должна быть жёстко задана в коде: при вводе матрицы большей размерности программа должна продолжать корректно работать, если входные данные соответствуют условиям применимости метода[cite: 7].
4. Использовать готовые реализации численных методов нельзя. Например, **NumPy** можно применять только для проверки и сравнения результатов собственной реализации, если в требованиях к конкретному заданию не указано иное[cite: 7].
