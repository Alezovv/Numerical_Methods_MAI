## Задание 4.1. Численное решение задачи Коши для ОДУ 2-го порядка

### Условие
Реализовать методы **Эйлера**, **Рунге-Кутты 4-го порядка** и **Адамса 4-го порядка** в виде программ, задавая в качестве входных данных шаг сетки $h$. С использованием разработанного программного обеспечения решить задачу Коши для ОДУ 2-го порядка на указанном отрезке. Оценить погрешность численного решения с использованием метода Рунге – Ромберга и путем сравнения с точным решением.

### Постановка задачи для 7-го варианта
* **Дифференциальное уравнение 2-го порядка:**
  $$y'' - 4x y' + (4x^2 - 2)y = 0$$
* **Начальные условия:**
  $$y(0) = 1, \quad y'(0) = 1$$
* **Отрезок интегрирования и шаг сетки:**
  $$x \in [0, 1], \quad h = 0.1$$
* **Точное аналитическое решение:**
  $$y(x) = (1 + x) e^{x^2}$$

---

### Теоретические основы и алгоритмы (4.1)

#### 1. Сведение ОДУ 2-го порядка к системе двух ОДУ 1-го порядка
Введем замену $z(x) = y'(x)$. Получаем систему:
$$
\begin{cases}
y' = z = f_1(x, y, z), \\
z' = 4x z - (4x^2 - 2)y = f_2(x, y, z)
\end{cases}
$$
с начальными условиями: $y(0) = 1, \; z(0) = 1$.

#### 2. Метод Эйлера (1-й порядок точности, $p = 1$)
$$y_{k+1} = y_k + h \cdot z_k$$
$$z_{k+1} = z_k + h \cdot f_2(x_k, y_k, z_k)$$

#### 3. Метод Рунге-Кутты 4-го порядка ($p = 4$)
На каждом шаге вычисляются четыре коэффициента:
$$
\begin{aligned}
k_{1,y} &= z_k, & k_{1,z} &= f_2(x_k, y_k, z_k) \\
k_{2,y} &= z_k + \frac{h}{2} k_{1,z}, & k_{2,z} &= f_2\left(x_k + \frac{h}{2}, y_k + \frac{h}{2} k_{1,y}, z_k + \frac{h}{2} k_{1,z}\right) \\
k_{3,y} &= z_k + \frac{h}{2} k_{2,z}, & k_{3,z} &= f_2\left(x_k + \frac{h}{2}, y_k + \frac{h}{2} k_{2,y}, z_k + \frac{h}{2} k_{2,z}\right) \\
k_{4,y} &= z_k + h \cdot k_{3,z}, & k_{4,z} &= f_2(x_k + h, y_k + h \cdot k_{3,y}, z_k + h \cdot k_{3,z})
\end{aligned}
$$
Следующее приближение:
$$y_{k+1} = y_k + \frac{h}{6} (k_{1,y} + 2k_{2,y} + 2k_{3,y} + k_{4,y})$$
$$z_{k+1} = z_k + \frac{h}{6} (k_{1,z} + 2k_{2,z} + 2k_{3,z} + k_{4,z})$$

#### 4. Метод Адамса 4-го порядка ($p = 4$)
Первые 4 точки ($k = 0, 1, 2, 3$) вычисляются одношаговым методом Рунге-Кутты 4-го порядка.
Для последующих точек ($k = 3, 4, \dots, N-1$) используется схема типа «предиктор-корректор»:
* **Предиктор (экстраполяционный метод Адамса-Башфорта 4-го порядка):**
  $$y_{k+1}^{(p)} = y_k + \frac{h}{24} (55 f_{1,k} - 59 f_{1,k-1} + 37 f_{1,k-2} - 9 f_{1,k-3})$$
  $$z_{k+1}^{(p)} = z_k + \frac{h}{24} (55 f_{2,k} - 59 f_{2,k-1} + 37 f_{2,k-2} - 9 f_{2,k-3})$$
* **Корректор (интерполяционный метод Адамса-Моултона 4-го порядка):**
  $$y_{k+1} = y_k + \frac{h}{24} (9 f_1(x_{k+1}, y_{k+1}^{(p)}, z_{k+1}^{(p)}) + 19 f_{1,k} - 5 f_{1,k-1} + f_{1,k-2})$$
  $$z_{k+1} = z_k + \frac{h}{24} (9 f_2(x_{k+1}, y_{k+1}^{(p)}, z_{k+1}^{(p)}) + 19 f_{2,k} - 5 f_{2,k-1} + f_{2,k-2})$$

#### 5. Оценка погрешности по правилу Рунге – Ромберга – Ричардсона
Решение вычисляется с шагом $h$ и половинным шагом $h/2$. В совпадающих узлах сетки погрешность оценивается как:
$$R_h(x_k) = \frac{|y_{h/2}(x_k) - y_h(x_k)|}{2^p - 1}$$
где $p = 1$ для метода Эйлера, $p = 4$ для методов Рунге-Кутты и Адамса.

## Задание 4.2. Численное решение краевой задачи для ОДУ 2-го порядка

### Условие
Реализовать **метод стрельбы** и **конечно-разностный метод** решения краевой задачи для ОДУ в виде программ. С использованием разработанного программного обеспечения решить краевую задачу для ОДУ 2-го порядка на указанном отрезке. Оценить погрешность численного решения с использованием метода Рунге – Ромберга и путем сравнения с точным решением.

### Постановка задачи для 7-го варианта
* **Дифференциальное уравнение 2-го порядка:**
  $$(2x + 1) y'' + 4x y' - 4y = 0, \quad x \in [0, 1]$$
* **Краевые условия:**
  $$y'(0) = -1$$
  $$y'(1) + 2y(1) = 3$$
* **Шаг сетки:**
  $$h = 0.1$$
* **Точное аналитическое решение:**
  $$y(x) = x + e^{-2x}$$

---

### Теоретические основы и алгоритмы (4.2)

#### 1. Метод стрельбы (пристрелки)
Уравнение разрешается относительно старшей производной:
$$y'' = \frac{4y - 4xy'}{2x + 1}$$
Краевое условие на левом конце задаёт производную $y'(0) = -1$, а само значение $y(0)$ неизвестно. Обозначим его через параметр стрельбы:
$$y(0) = \eta$$
Для каждого фиксированного $\eta$ решается вспомогательная задача Коши методом Рунге-Кутты 4-го порядка:
$$
\begin{cases}
y' = z, & y(0) = \eta \\
z' = \dfrac{4y - 4xz}{2x + 1}, & z(0) = -1
\end{cases}
$$
Требуется удовлетворить правому краевому условию в точке $x = 1$, то есть найти корень функции невязки:
$$\Phi(\eta) = z(1; \eta) + 2 y(1; \eta) - 3 = 0$$
Поскольку дифференциальное уравнение линейно, функция $\Phi(\eta)$ линейна по $\eta$. Для поиска оптимального $\eta^*$ используется метод секущих:
$$\eta_{k+1} = \eta_k - \Phi(\eta_k) \frac{\eta_k - \eta_{k-1}}{\Phi(\eta_k) - \Phi(\eta_{k-1})}$$
Для линейной задачи метод находит точный параметр $\eta^* = 1.0$ за 1 шаг.
Порядок погрешности метода стрельбы определяется порядком метода интегрирования (РК4, $p = 4$).

#### 2. Конечно-разностный метод
Приводим уравнение к каноническому виду $y'' + p(x)y' + q(x)y = f(x)$:
$$p(x) = \frac{4x}{2x + 1}, \quad q(x) = -\frac{4}{2x + 1}, \quad f(x) = 0$$
Вводим сетку $x_i = a + ih, \; i = 0, \dots, N$.
Аппроксимируем производные центральными разностями второго порядка точности $O(h^2)$:
$$y''_i \approx \frac{y_{i+1} - 2y_i + y_{i-1}}{h^2}, \qquad y'_i \approx \frac{y_{i+1} - y_{i-1}}{2h}$$
Во внутренних узлах $i = 1, \dots, N-1$ получаем трехдиагональные уравнения:
$$A_i y_{i-1} + B_i y_i + C_i y_{i+1} = D_i$$
где:
$$A_i = 1 - \frac{h}{2} p(x_i), \quad B_i = -2 + h^2 q(x_i), \quad C_i = 1 + \frac{h}{2} p(x_i), \quad D_i = h^2 f(x_i) = 0$$

##### Аппроксимация краевых условий с погрешностью $O(h^2)$:
* **Левый конец ($x = 0$):** $y'(0) = -1$.
  Вводим фиктивный узел $x_{-1}$: $\dfrac{y_1 - y_{-1}}{2h} = -1 \implies y_{-1} = y_1 + 2h$.
  Подставляя $y_{-1}$ в разностное уравнение при $i = 0$, получаем:
  $$B_0 = -2 + h^2 q(0), \quad C_0 = 2, \quad D_0 = -2h \left(1 - \frac{h}{2} p(0)\right)$$
* **Правый конец ($x = 1$):** $y'(1) + 2y(1) = 3$.
  Вводим фиктивный узел $x_{N+1}$: $\dfrac{y_{N+1} - y_{N-1}}{2h} + 2y_N = 3 \implies y_{N+1} = y_{N-1} - 4h y_N + 6h$.
  Подставляя $y_{N+1}$ в разностное уравнение при $i = N$, получаем:
  $$A_N = 2, \quad B_N = -2 + h^2 q(1) - 4h\left(1 + \frac{h}{2} p(1)\right), \quad D_N = -6h\left(1 + \frac{h}{2} p(1)\right)$$

Полученная трёхдиагональная система решается **методом прогонки** (алгоритм Томаса). Порядок точности схемы — $p = 2$.

## Сборка и запуск программы

### 1. Компиляция проекта через CMake
Из корневой директории репозитория:
```bash
cmake -B build
cmake --build build --config Release
```

### 2. Запуск программы
```bash
./build/bin/lab4.exe
```

После выполнения расчетов в C++ программе создаются файлы данных `data/lab4/plot_4_1.csv` и `data/lab4/plot_4_2.csv`.

Скрипты выведут графики на экран и сохранят готовые рисунки в:
